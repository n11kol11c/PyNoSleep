# PyNoSleep

A small Python script that randomly moves your mouse cursor every few seconds to help prevent your computer from becoming idle.

## Requirements

* Python 3.x
* PyAutoGUI

## Installation

Clone or download the project, then install the dependency:

```bash
pip install -r requirements.txt
```

## Usage

Run:

```bash
python main.py
```

The cursor will move to a random position on your screen every few seconds.

Press **Ctrl+C** to stop the program.

## requirements.txt

```txt
PyAutoGUI
```
